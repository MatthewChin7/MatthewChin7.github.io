# Marginalia

Short entries (one sentence to ~500 words) stored as JSON in
`marginalia.json`, validated against `marginaliaSchema`.

**The current entries are SAMPLE CONTENT** written to demonstrate the
system — intellectual observations and questions consistent with the
site's subjects, not quotations from Matthew. Replace or edit them freely;
`pnpm new:musing` scaffolds a new entry, or use `/admin` while running
locally.
