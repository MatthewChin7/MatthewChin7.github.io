## Abstract

Code.org serves students in dozens of languages, which turns every UI
string, curriculum page, and interactive widget into a dependency-managed
artifact. This work involved React and Rails development around
localization workflows and mobile-friendly interaction patterns —
the unglamorous infrastructure that decides whether a translated lesson
actually renders correctly for a student.

## The problem shape

Localization at platform scale is a graph problem: strings belong to
components, components to lessons, lessons to courses, and translations
lag sources by varying amounts per locale. The failure modes are quiet —
a fallback string here, a clipped layout in a long-word language there —
so the tooling's job is to make staleness and overflow _visible_ before
students see them.

## Themes

- Keeping translated content renderable: pluralization, RTL, and
  length-expansion tolerance as design constraints, not afterthoughts.
- Mobile-friendly interaction patterns for classrooms where the only
  device is a phone.
- Workflow design so translators, curriculum writers, and engineers can
  work concurrently without stepping on each other.
